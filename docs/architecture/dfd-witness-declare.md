# Data flow: one task's witness row (a40, 2026-11-12)

Status: requested by Trony (BellTeam coordinator) for ~15 members on one repo, each
declaring their own task's files; adopted by Snow White. Canonical ownership is in
[function-map](function-map.md). The draft → witness set → compile contracts are
unchanged (ADR 0127, ADR 0136, a32/a35); this command composes them for one row.

| Owner / step | Input / read | Output / decision | Failure / recovery |
|---|---|---|---|
| Independence: `todo independence witness declare --plan <key> --task <id> [--owns <path>[#<function>][,…]] [--reads <path>[#<function>][,…]] [--writes …]` | Fresh Store member; the plan's recorded witness set (`readTodoWitnessSet`, unreadable = none, as the a35 template) | Draft = `witnessDraftTemplateFor` restricted to rows the witness set already records plus this task, with this task's row replaced by the flags (comma-separated repo-relative paths; omitted = `[]`). `path#function` (ADR 0204 §1, a3b, `src/todo-declaration.mjs`): split at the first `#` (`parseAnchor`); the path joins `owns`/`reads`, the function goes to `concern_anchors` (owns) or `read_anchors` (reads) of that row, as the dotted name the task wrote; all names of the command are resolved in one call to the code graph's Resolve (`resolveAnchors`) before anything is written. A row with `read_anchors` makes the plan's set `lattice.todo_witness_set.v6`; every other set stays v5. A row nobody declared is never written as empty: an empty row would claim "touches nothing". Concern anchors and unknowns of other rows are kept by the template; this task's row has none (use the draft route for them). | Plan not active → `plan_not_active`; task not in the plan → `TASK_NOT_FOUND/task_not_found`; task done or retired → `INPUT_INVALID/witness_declare_task_finished` (its row would be dropped by the template). All before any write. Functions: a name that does not resolve, an entry that is not `path#dotted.name`, a Store root with no code tree (`no_code_tree`) or a Resolve that cannot answer (`resolve_unavailable`) never fail the command: exit 0, `declaration.written: false`, the task's row is NOT written, and `next_action` lists the names with the nearest ones; the same declare retried succeeds from scratch. No index yet: Resolve's first call runs one `sensor init` (later calls reuse it). |
| Independence: scaffold | That draft | Same path as `witness scaffold --input`: fresh affected-test observation, query wiring, digest; writes `.lattice/todo/witness/<key>.json`. | Draft and scaffold refusals unchanged (`WITNESS_DRAFT_INVALID`, `WITNESS_SCAFFOLD_INCOMPLETE`) with their next_action. Nothing written on refusal. |
| Independence: compile over the declared rows (g4) | Written witness set, current ready tasks of the plan | The existing `independence compile` on the written ref runs whenever HEAD resolves; the result names `waiting_for` (ready tasks not yet declared). An undeclared ready task is `witness_missing` for itself only and is kept out of every parallel group, so it stays "not judged", never "safe". | Compile refusals unchanged, except `INDEPENDENCE_READY_UNDECLARED`, which no longer exists. Observation (a2, ADR 0204 Observe, `collectTodoIndependenceAuthoritativeObservation` over `withObservedTree`, which Touched also uses for its range end): when the work tree outside `.lattice/` is clean at HEAD, the sensor queries run on the tree's own maintained index after an incremental `sensor sync` (first use on a tree without an index: one `sensor init`); clean and HEAD are checked before and after the sync, and a break falls through. A dirty tree is never observed: it falls back to the detached worktree of HEAD with a fresh index, as before (protects the judgment from uncommitted state; the exit is the fallback itself, nothing is refused). |
| Independence: result | — | `lattice.todo_witness_declare_result.v2` `{project_id, plan_key, task_id, declaration: {written, resolved: [{path, symbol, kind, start_line, end_line}], new_names: [{path, symbol, nearest[], elsewhere[]}] (names kept in the row as `new_symbols`, ADR 0204 §7), unresolved: [{path, symbol, reason, nearest[], elsewhere[]}] (path_invalid / symbol_empty only; the row is not written), malformed: [{text, reason}]}, owns, reads, writes, witness_ref, witness_set_digest, compiled, waiting_for, compile, result_digest}`; `compile` is the compile result or null. When `declaration.written` is false the result has `witness_ref`/`witness_set_digest` null, `compiled: false` and a `next_action`; `owns`/`reads`/`writes` are absent. | — |
| Independence: Store root with no commit (declare-without-git, 2026-11-12) | `headResolves(repoRoot)` (`git rev-parse HEAD`; unresolved = unborn HEAD, e.g. the BellTeam MCP store) | The row is scaffolded and written as above; compile is skipped even when every ready task is declared. Result adds `observation: "unavailable"` and `next_action`: `todo start` for the task only when it is ready (`createTodoReadiness.isReady`); a pending task that is not ready gets the unfinished predecessors or unaccepted phases (`prerequisites().blocking`, the set a start refusal names) or its own phase status, and a started or blocked task gets its status (declare-hint-knows-order, 2026-11-12). `startAdvisory`: no artifact, HEAD unresolved and the recorded witness set has a row for the task → `coverage: "declared_unobserved"`, `self_unknowns: [{kind: observation_unavailable, ref: git_head_unresolved}]`, guidance `independence_declared_unobserved` (next_action `none`); never `verified`. | A task without a row keeps `coverage: missing` (gate 1 still refuses it on an enforced plan). After the first commit, the next declare compiles as usual. |

Protected state: other tasks' recorded rows (kept as recorded), the independence
artifact (written only by compile). No new judgement: what a task owns is the
member's statement; the machine adds observation and digests only.
